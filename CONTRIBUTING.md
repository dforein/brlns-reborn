1) The reproduction of brlns minigames should be as accurate as possible. It's not allowed to add additional features not present originally (unless when covering *temporary* holes).
2) When there are different versions of the same thing that were in brlns in different periods of time (for example: scoreboard appearance changes), choose the one you like the most. 
3) There are 4 main focuses when contributing:
   - implementing new features from original brlns server
   - fixing bugs
   - cleaning the code
   - abstracting the code, to make all the minigames recreations development easier
